The latest stable version is **Quetzal Language v0.0.3**. Official packages include the `quetzal` interpreter and the `quetzal-lsp` language server.

## Download Quetzal

Download the package for your system from the [official GitHub releases](https://github.com/AntaresGT/lenguaje-quetzal/releases/latest).

| System | Package | Contents |
|--------|---------|----------|
| Windows | [quetzal-windows-msi.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-windows-msi.zip) | MSI installer for Windows x86_64 |
| Windows | [quetzal-windows.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-windows.zip) | Portable executables |
| Linux | [quetzal-linux.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-linux.zip) | Executables for Linux x86_64 |
| Ubuntu | [quetzal-ubuntu.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-ubuntu.zip) | Ubuntu-specific package |
| Fedora | [quetzal-fedora.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-fedora.zip) | Fedora-specific package |
| Linux | [quetzal-appimage.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-appimage.zip) | AppImage package |

<Aside type="note">
There is no macOS package in the v0.0.3 release. On that system, you can build the interpreter from source.
</Aside>

## Install on Windows

<Tabs>
  <TabItem label="MSI installer">

<Steps>

1. Download `quetzal-windows-msi.zip` and extract it.
2. Run `quetzal-0.0.3-x86_64.msi` and complete the installation wizard.
3. Open a new terminal and verify the installation:

   ```powershell
   quetzal --version
   ```

   The output should be:

   ```text
   Quetzal v0.0.3
   ```

</Steps>

If the command is not recognized, add the directory containing `quetzal.exe` to your `PATH` and open a new terminal.

  </TabItem>
  <TabItem label="Portable executable">

<Steps>

1. Download and extract `quetzal-windows.zip`.
2. Store the executables in a permanent folder, such as `C:\quetzal`.
3. Add `C:\quetzal` to the `Path` environment variable.
4. Open a new terminal and run `quetzal --version`.

</Steps>

  </TabItem>
</Tabs>

## Install on Linux

The general `quetzal-linux.zip` package contains `quetzal` and `quetzal-lsp`. Ubuntu and Fedora users can also choose their distribution-specific package.

```bash
unzip quetzal-linux.zip -d quetzal
cd quetzal
chmod +x quetzal quetzal-lsp
./quetzal --version
```

To run `quetzal` from any directory, move the executables to a directory in your `PATH` or add their current location to your terminal's `PATH`.

If you downloaded the AppImage package, extract it, make the `.AppImage` file executable, and run it from the terminal.

## Build from source

You need [Git](https://git-scm.com/) and an up-to-date [Rust](https://rustup.rs/) installation compatible with the 2024 edition.

```bash
git clone https://github.com/AntaresGT/lenguaje-quetzal.git
cd lenguaje-quetzal
cargo build --release
```

The interpreter is created at `target/release/quetzal` (`quetzal.exe` on Windows). Run an example program to verify the build:

```bash
./target/release/quetzal ejemplos/hola_mundo/principal.qz
```

You can also build and run without copying the binary:

```bash
cargo run -p lnc -- ejemplos/hola_mundo/principal.qz
```

## Use the interpreter

```bash
# Run a file
quetzal program.qz

# Analyze a file without running it
quetzal revisar program.qz

# Create a project
quetzal nuevo my-project

# Open the interactive REPL
quetzal

# Show help and version
quetzal ayuda
quetzal --version
```

Version 0.0.3 supports `--jit`, `--sin-jit`, and `--sin-optimizar` to control JIT compilation and optimizations during execution. Quetzal remains an interpreted language: JIT is an internal optimization for compatible functions.

## Verify the installation

Create a file named `hello.qz`:

```qz
consola.mostrar_exito("¡Hola, mundo desde Quetzal!")
```

Run the file:

```bash
quetzal hello.qz
```

## Editor extensions

The `quetzal-lsp` server provides diagnostics, completion, symbol information, and go-to-definition. Official extensions integrate it with these editors:

- [Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=AntaresGT.lenguaje-quetzal-vscode-extension): `code --install-extension AntaresGT.lenguaje-quetzal-vscode-extension`
- [Neovim](https://github.com/AntaresGT/lenguaje-quetzal.nvim)
- [Zed](https://github.com/AntaresGT/lenguaje-quetzal-zed-extension)

## Update Quetzal

Download the package for the new version and replace the previous installation, or rebuild from the updated source. Then run `quetzal --version` to confirm the active version.
