## Current version: v0.0.3

Quetzal Language v0.0.3 retains the v0.0.2 features and adds:

- Virtual-machine, bytecode, function-call, and loop optimizations.
- Selective JIT compilation through Cranelift for compatible functions.
- `--jit`, `--sin-jit`, and `--sin-optimizar` options.
- The `quetzal-lsp` language server with diagnostics, completion, and go-to-definition.
- Extensions for Visual Studio Code, Neovim, and Zed.
- `quetzal` and `quetzal-lsp` executables in the Windows and Linux packages.
- Stability, exception-handling, and compatibility improvements for existing programs.
- Interruption of `mientras` statements.

See the [complete v0.0.3 release notes](https://github.com/AntaresGT/lenguaje-quetzal/releases/tag/v0.0.3).

## v0.0.2

- Explicit static typing and default immutability with `var`.
- User modules with `importar` and `exportar`.
- Exceptions with `intentar`, `capturar`, `finalmente`, and `lanzar`.
- Single and multiple inheritance, prototypes, and `libre` members.
- Asynchronous functions and named callbacks.
- Lists, native JSON, and built-in methods by type.
- Standard library for console, mathematics, time, regular expressions, files, and networking.
- `quetzal.json` manifest and declarative permissions.
- Interactive REPL.

## v0.0.1

- Basic interpreter implemented in Rust.
- Fundamental data types and user-defined functions.
- Conditionals, loops, and native JSON.
- Visual Studio Code extension.

## Upcoming versions

The project's published direction for v0.1.0 includes:

- More mature package management.
- Integrated debugger.
- More complete REST APIs for production environments.
- Database connections.
- Additional development tools.

Proposals for later versions may change. [GitHub releases](https://github.com/AntaresGT/lenguaje-quetzal/releases) are the reference for published features.
