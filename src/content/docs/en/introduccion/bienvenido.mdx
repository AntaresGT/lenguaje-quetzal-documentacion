**Quetzal Language** is an interpreted programming language implemented in Rust with Spanish syntax. It uses explicit static typing and validates code before running it on its virtual machine.

## Language features

<CardGrid>
  <Card title="Types and data" icon="document">
    Includes `entero`, `número`, `texto`, `log`, `vacio`, `nulo`, typed or heterogeneous lists, native JSON through `jsn`, and functions as values through the `funcion` type.
  </Card>
  <Card title="Explicit mutability" icon="setting">
    Declarations are immutable by default. The `var` keyword allows variable reassignment and collection mutation.
  </Card>
  <Card title="Functions and async" icon="rocket">
    Functions have explicit types, support recursion and named callbacks, and can use `asincrono` and `esperar`.
  </Card>
  <Card title="Object-oriented programming" icon="sourcehut">
    `objeto` and `prototipo` support constructors, visibility, `libre` members, single or multiple inheritance, and interface implementation.
  </Card>
</CardGrid>

## What is included in v0.0.3

- **User modules** with `importar`, `exportar`, `desde`, and aliases through `como`.
- **Exceptions** with `intentar`, `capturar`, `finalmente`, and `lanzar`.
- **Standard library** with console, mathematics, dates and times, regular expressions, file system, and HTTP networking.
- **Declarative permissions** in `quetzal.json` to control access to files, networking, and process execution.
- **Interactive REPL** and commands to run, check, and create projects.
- **Selective JIT** to accelerate compatible functions, with `--jit`, `--sin-jit`, and `--sin-optimizar` options.
- **`quetzal-lsp` language server** with diagnostics, completion, symbol information, and go-to-definition.
- **Official extensions** for Visual Studio Code, Neovim, and Zed.

JIT is an interpreter optimization; Quetzal remains an interpreted language.

## First look at the language

```qz
importar { Matemática } desde "quetzal/matemática"

texto var nombre = "Quetzal"
lista<entero> numeros = [1, 2, 3, 4]

entero sumar(entero a, entero b) {
    retornar a + b
}

entero resultado = sumar(7, 3)
número raiz = Matemática.raiz_cuadrada(16)

consola.mostrar(t"Hola desde {nombre}")
consola.mostrar(t"7 + 3 = {resultado}")
consola.mostrar(t"Raíz cuadrada de 16 = {raiz}")
```
