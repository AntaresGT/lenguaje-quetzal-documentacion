## Create a project

The `nuevo` command generates the initial structure:

```bash
quetzal nuevo my-project
```

A typical structure is:

<FileTree>
- my-project/
  - quetzal.json
  - principal.qz
  - modulos/
    - usuarios.qz
    - utilidades.qz
  - datos/
</FileTree>

Code files use the `.qz` extension. Imports between files use relative paths:

```qz
importar { Usuario } desde "./modulos/usuarios.qz"
```

## `quetzal.json` manifest

The manifest defines metadata, the entry file, the required Quetzal version, dependencies, and project permissions. Its canonical field names retain Spanish accents.

```json
{
  "versión": "1.0.0",
  "aplicación": "my-project",
  "entrada": "principal.qz",
  "tipo": "aplicación",
  "quetzal": "0.0.3",
  "dependencias": {}
}
```

| Field | Description |
|-------|-------------|
| `versión` | Manifest format version. |
| `aplicación` | Project name. |
| `entrada` | Main `.qz` file. |
| `tipo` | `aplicación` for a program or `biblioteca` for importable code. |
| `quetzal` | Required language version. |
| `dependencias` | Dependencies and their versions or URLs. |

<Aside type="note">
Without `quetzal.json`, the interpreter applies secure defaults and blocks file-system and network access.
</Aside>

## Permissions

Available permissions are `sistema-archivos`, `red`, `entorno`, and `ejecución`.

```json
{
  "versión": "1.0.0",
  "aplicación": "my-project",
  "entrada": "principal.qz",
  "tipo": "aplicación",
  "quetzal": "0.0.3",
  "permisos": [
    {
      "tipo": "sistema-archivos",
      "habilitado": true,
      "directorios": [
        { "ruta": "./datos", "permiso": "lectura" },
        { "ruta": "./salida", "permiso": "todo" }
      ]
    },
    {
      "tipo": "red",
      "habilitado": true
    }
  ]
}
```

For the file system, each directory declares `lectura`, `escritura`, or `todo`. The `red` permission enables HTTP clients and servers. The `entorno` permission allows reading system variables and loading `.env` files. The `ejecución` permission includes an `ejecutables` list for authorized external processes.

Grant only the permissions and paths the program needs.

## Native modules

```qz
importar { Matemática } desde "quetzal/matemática"
importar { Tiempo } desde "quetzal/tiempo"
importar { ExpresiónRegular } desde "quetzal/motor"
importar { entorno } desde "quetzal/entorno"
importar { SistemaArchivos } desde "quetzal/sistema_archivos"
importar { ClienteHttp } desde "quetzal/red"
```
