Quetzal uses `importar` and `exportar` to share code between files.

## Exporting

Use the `exportar` block at the end of a file to make symbols available to other files.

```qz
// file: utilidades.qz

entero sumar(entero a, entero b) {
    retornar a + b
}

objeto Calculadora {
    libre numero multiplicar(numero a, numero b) {
        retornar a * b
    }
}

texto VERSION = "1.0.0"

exportar {
    sumar,
    Calculadora,
    VERSION
}
```

## Importing

Use `importar` with `desde` to bring symbols from another file.

```qz
// file: principal.qz

importar {
    sumar,
    Calculadora,
    VERSION
} desde "utilidades.qz"

entero resultado = sumar(5, 3)
numero producto = Calculadora.multiplicar(4.5, 2.0)
consola.mostrar("Version: " + VERSION)
```

## Import with Alias

Use `como` to rename imported symbols.

```qz
importar {
    sumar como suma_enteros,
    Calculadora como Calc,
    VERSION como version_actual
} desde "utilidades.qz"

entero resultado = suma_enteros(10, 20)
```

## Native Modules

Quetzal provides built-in modules with the `quetzal/` prefix.

```qz
importar { Matemática } desde "quetzal/matemática"

número pi = Matemática.PI
número resultado = Matemática.sumar(2, 3)
número seno = Matemática.seno(Matemática.PI / 2)
```

### Available Native Modules

| Module | Description |
|--------|-------------|
| `quetzal/matemática` | Mathematical functions and constants |
| `quetzal/tiempo` | Dates, times, and time zones |
| `quetzal/motor` | Regular expressions |
| `quetzal/entorno` | Environment variables; requires `entorno` permission |
| `quetzal/sistema_archivos` | File-system operations; requires `sistema-archivos` permission |
| `quetzal/red` | HTTP clients and servers; requires `red` permission |

<Aside type="note">
Native modules are distributed with the interpreter. File-system, networking, and environment-variable operations require their corresponding permissions in `quetzal.json`.
</Aside>

## Relative Paths

Paths are relative to the main file that invokes the interpreter.

```qz
importar { Usuario } desde "./modulos/usuarios.qz"
importar { validar } desde "../compartido/validaciones.qz"
```

## Best Practices

- Export only what other modules need
- Use descriptive names for exported symbols
- Group related functionality in the same module
- Document exported symbols with comments
