---
title: Asynchronous functions
description: Declare and run asynchronous functions with asincrono and esperar in Quetzal Language.
---

Asynchronous functions are available in Quetzal Language. Declare them with `asincrono` (or `asincróno`) and obtain their results with `esperar`.

## Declare an asynchronous function

Place the modifier before the return type:

```qz
asincrono entero doble(entero valor) {
    retornar valor * 2
}
```

## Wait for the result

`esperar` can be used inside another asynchronous function or at the top level of the entry file:

```qz
asincrono entero doble(entero valor) {
    retornar valor * 2
}

entero resultado = esperar doble(21)
consola.mostrar(t"Resultado: {resultado}")
```

Inside a function:

```qz
asincrono vacio ejecutar() {
    entero resultado = esperar doble(10)
    consola.mostrar(resultado.texto())
}

esperar ejecutar()
```

## Asynchronous standard-library operations

The file-system and networking modules provide variants with the `_asincrono` suffix. These variants allow the event loop to continue handling other operations.

```qz
importar { SistemaArchivos } desde "quetzal/sistema_archivos"

asincrono vacio copiar_datos() {
    texto datos = esperar SistemaArchivos.leer_asincrono("./entrada.txt")
    esperar SistemaArchivos.escribir_asincrono("./salida.txt", datos)
}

esperar copiar_datos()
```

File access requires the corresponding permissions in `quetzal.json`.

## Rules

- Declare the return type after `asincrono`.
- Place `esperar` before the call that produces the task.
- Parameters, return values, and exceptions follow the same type rules as synchronous functions.
- Asynchronous callbacks are declared with a name; Quetzal does not have anonymous functions.
