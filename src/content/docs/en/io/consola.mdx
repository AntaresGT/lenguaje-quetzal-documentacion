---
title: Console
description: Console methods for input and output in Quetzal Language.
---

The global `consola` object provides methods for displaying messages and receiving user input. It is available without an import.

## Display messages

| Method | Description |
|--------|-------------|
| `consola.mostrar(texto)` | Prints text using the default color. |
| `consola.mostrar_error(texto)` | Prints an error in red. |
| `consola.mostrar_advertencia(texto)` | Prints a warning in yellow. |
| `consola.mostrar_exito(texto)` | Prints a success message in green. |
| `consola.mostrar_informacion(texto)` | Prints information in blue. |

```qz
consola.mostrar("Normal message")
consola.mostrar_exito("Operation completed successfully!")
consola.mostrar_error("An error occurred")
consola.mostrar_advertencia("Check this value")
consola.mostrar_informacion("Processing data...")
```

## Read input

```qz
texto nombre = consola.pedir("Enter your name: ")
texto contrasena = consola.pedir_secreto("Enter password: ")
```

`pedir` returns the entered text. `pedir_secreto` reads without echoing the input.

## Display non-text values

Convert values to text before displaying them:

```qz
entero numero = 42
lista<entero> lista = [1, 2, 3]
jsn datos = { nombre: "Ana" }

consola.mostrar(numero.texto())
consola.mostrar(lista.texto())
consola.mostrar(datos.texto_formateado())
```

Or use text interpolation:

```qz
entero edad = 25
consola.mostrar(t"You are {edad} years old")
```

Output colors depend on terminal support. Avoid interactive input in automated scripts.
