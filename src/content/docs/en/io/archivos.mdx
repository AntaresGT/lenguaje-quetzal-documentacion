The `quetzal/sistema_archivos` module supports text and binary files, directories, cursor-based streams, and change watchers.

<Aside type="caution">
File operations require the `sistema-archivos` permission in `quetzal.json`. Without it, the interpreter blocks access.
</Aside>

## Configure permissions

Declare each directory and its required access level:

```json
{
  "versión": "1.0.0",
  "aplicación": "my-project",
  "entrada": "principal.qz",
  "tipo": "aplicación",
  "quetzal": "0.0.3",
  "permisos": [
    {
      "tipo": "sistema-archivos",
      "habilitado": true,
      "directorios": [
        { "ruta": "./datos", "permiso": "lectura" },
        { "ruta": "./salida", "permiso": "escritura" }
      ]
    }
  ]
}
```

Available levels are `lectura`, `escritura`, and `todo`. Relative paths are resolved from the project root; `"*"` allows any path.

## Read and write text

```qz
importar { SistemaArchivos } desde "quetzal/sistema_archivos"

SistemaArchivos.crear_directorios("./salida")
SistemaArchivos.escribir("./salida/resultado.txt", "Hola, Quetzal")

texto contenido = SistemaArchivos.leer("./salida/resultado.txt")
consola.mostrar(contenido)
```

`escribir` creates or overwrites the file. To append content, use `anexar`.

## Inspect files and directories

```qz
log existe = SistemaArchivos.existe("./salida/resultado.txt")
log es_archivo = SistemaArchivos.es_archivo("./salida/resultado.txt")
lista<texto> archivos = SistemaArchivos.listar_archivos("./salida")
```

You can also obtain a reference with metadata:

```qz
importar { SistemaArchivos, Archivo } desde "quetzal/sistema_archivos"

Archivo archivo = SistemaArchivos.abrir("./salida/resultado.txt")
consola.mostrar(archivo.nombre())
consola.mostrar(archivo.tamaño().texto())
```

## Binary data

`Bits` represents an in-memory byte sequence:

```qz
importar { SistemaArchivos, Bits } desde "quetzal/sistema_archivos"

Bits datos = Bits.desde_texto("Quetzal")
SistemaArchivos.escribir_bits("./salida/datos.bin", datos)

Bits leidos = SistemaArchivos.leer_bits("./salida/datos.bin")
consola.mostrar(leidos.texto())
```

## Asynchronous operations

I/O operations have a variant with the `_asincrono` suffix, used with `esperar`:

```qz
asincrono vacio guardar() {
    esperar SistemaArchivos.escribir_asincrono("./salida/datos.txt", "contenido")
    texto datos = esperar SistemaArchivos.leer_asincrono("./salida/datos.txt")
    consola.mostrar(datos)
}

esperar guardar()
```

## Handle errors

Insufficient permissions, unauthorized paths, and operating-system errors produce catchable exceptions:

```qz
intentar {
    texto contenido = SistemaArchivos.leer("./datos/config.txt")
    consola.mostrar(contenido)
} capturar (excepcion error) {
    consola.mostrar_error(error.mensaje)
}
```

The module also includes `Flujo` for incremental reading and writing with a persistent cursor, and `Observador` for file and directory change events.
