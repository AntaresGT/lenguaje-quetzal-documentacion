**Lenguaje Quetzal** es un lenguaje de programación interpretado, implementado en Rust y con sintaxis en español. Utiliza tipado estático explícito y valida el código antes de ejecutarlo en su máquina virtual.

## Características del lenguaje

<CardGrid>
  <Card title="Tipos y datos" icon="document">
    Incluye `entero`, `número`, `texto`, `log`, `vacio`, `nulo`, listas tipadas o heterogéneas, JSON nativo mediante `jsn` y funciones como valores mediante el tipo `funcion`.
  </Card>
  <Card title="Mutabilidad explícita" icon="setting">
    Las declaraciones son inmutables de forma predeterminada. La palabra clave `var` permite reasignar variables y modificar colecciones.
  </Card>
  <Card title="Funciones y asincronía" icon="rocket">
    Las funciones tienen tipos explícitos, admiten recursión y callbacks nombrados, y pueden usar `asincrono` y `esperar`.
  </Card>
  <Card title="Programación orientada a objetos" icon="sourcehut">
    Los `objeto` y `prototipo` admiten constructores, visibilidad, miembros `libre`, herencia simple o múltiple e implementación de interfaces.
  </Card>
</CardGrid>

## Qué incluye la versión v0.0.3

- **Módulos de usuario** con `importar`, `exportar`, `desde` y alias mediante `como`.
- **Excepciones** con `intentar`, `capturar`, `finalmente` y `lanzar`.
- **Biblioteca estándar** con consola, matemáticas, fechas y horas, expresiones regulares, sistema de archivos y red HTTP.
- **Permisos declarativos** en `quetzal.json` para controlar el acceso a archivos, red y ejecución de procesos.
- **REPL interactivo** y comandos para ejecutar, revisar y crear proyectos.
- **JIT selectivo** para acelerar funciones compatibles, con las opciones `--jit`, `--sin-jit` y `--sin-optimizar`.
- **Servidor de lenguaje `quetzal-lsp`** con diagnósticos, autocompletado, información de símbolos y navegación a definiciones.
- **Extensiones oficiales** para Visual Studio Code, Neovim y Zed.

El JIT es una optimización del intérprete; Quetzal continúa siendo un lenguaje interpretado.

## Primer vistazo al lenguaje

```qz
importar { Matemática } desde "quetzal/matemática"

texto var nombre = "Quetzal"
lista<entero> numeros = [1, 2, 3, 4]

entero sumar(entero a, entero b) {
    retornar a + b
}

entero resultado = sumar(7, 3)
número raiz = Matemática.raiz_cuadrada(16)

consola.mostrar(t"Hola desde {nombre}")
consola.mostrar(t"7 + 3 = {resultado}")
consola.mostrar(t"Raíz cuadrada de 16 = {raiz}")
```
