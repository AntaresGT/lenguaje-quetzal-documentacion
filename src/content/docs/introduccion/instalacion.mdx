La versión estable más reciente es **Lenguaje Quetzal v0.0.3**. Los paquetes oficiales incluyen el intérprete `quetzal` y el servidor de lenguaje `quetzal-lsp`.

## Descargar Quetzal

Descarga el paquete correspondiente a tu sistema desde los [lanzamientos oficiales en GitHub](https://github.com/AntaresGT/lenguaje-quetzal/releases/latest).

| Sistema | Paquete | Contenido |
|---------|---------|-----------|
| Windows | [quetzal-windows-msi.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-windows-msi.zip) | Instalador MSI para Windows x86_64 |
| Windows | [quetzal-windows.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-windows.zip) | Ejecutables portables |
| Linux | [quetzal-linux.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-linux.zip) | Ejecutables para Linux x86_64 |
| Ubuntu | [quetzal-ubuntu.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-ubuntu.zip) | Paquete específico para Ubuntu |
| Fedora | [quetzal-fedora.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-fedora.zip) | Paquete específico para Fedora |
| Linux | [quetzal-appimage.zip](https://github.com/AntaresGT/lenguaje-quetzal/releases/download/v0.0.3/quetzal-appimage.zip) | Paquete AppImage |

<Aside type="note">
No hay un paquete para macOS en el lanzamiento v0.0.3. En ese sistema puedes compilar el intérprete desde el código fuente.
</Aside>

## Instalar en Windows

<Tabs>
  <TabItem label="Instalador MSI">

<Steps>

1. Descarga `quetzal-windows-msi.zip` y descomprime el archivo.
2. Ejecuta `quetzal-0.0.3-x86_64.msi` y completa el asistente de instalación.
3. Abre una terminal nueva y comprueba la instalación:

   ```powershell
   quetzal --version
   ```

   La salida debe ser:

   ```text
   Quetzal v0.0.3
   ```

</Steps>

Si el comando no se reconoce, agrega al `PATH` la carpeta donde el instalador guardó `quetzal.exe` y vuelve a abrir la terminal.

  </TabItem>
  <TabItem label="Ejecutable portable">

<Steps>

1. Descarga y descomprime `quetzal-windows.zip`.
2. Guarda los ejecutables en una carpeta permanente, por ejemplo `C:\quetzal`.
3. Agrega `C:\quetzal` a la variable de entorno `Path`.
4. Abre una terminal nueva y ejecuta `quetzal --version`.

</Steps>

  </TabItem>
</Tabs>

## Instalar en Linux

El paquete general `quetzal-linux.zip` contiene `quetzal` y `quetzal-lsp`. Si utilizas Ubuntu o Fedora, también puedes escoger su paquete específico.

```bash
unzip quetzal-linux.zip -d quetzal
cd quetzal
chmod +x quetzal quetzal-lsp
./quetzal --version
```

Para ejecutar `quetzal` desde cualquier directorio, mueve los ejecutables a una carpeta incluida en tu `PATH` o agrega su ubicación actual al `PATH` de tu terminal.

Si descargaste el paquete AppImage, descomprímelo, concede permiso de ejecución al archivo `.AppImage` y ejecútalo desde la terminal.

## Compilar desde el código fuente

Necesitas [Git](https://git-scm.com/) y una instalación actualizada de [Rust](https://rustup.rs/) compatible con la edición 2024.

```bash
git clone https://github.com/AntaresGT/lenguaje-quetzal.git
cd lenguaje-quetzal
cargo build --release
```

El intérprete queda en `target/release/quetzal` (`quetzal.exe` en Windows). Ejecuta un programa de ejemplo para comprobar la compilación:

```bash
./target/release/quetzal ejemplos/hola_mundo/principal.qz
```

También puedes compilar y ejecutar sin copiar el binario:

```bash
cargo run -p lnc -- ejemplos/hola_mundo/principal.qz
```

## Usar el intérprete

```bash
# Ejecutar un archivo
quetzal programa.qz

# Analizar un archivo sin ejecutarlo
quetzal revisar programa.qz

# Crear un proyecto
quetzal nuevo mi-proyecto

# Abrir el REPL interactivo
quetzal

# Consultar la ayuda y la versión
quetzal ayuda
quetzal --version
```

La versión 0.0.3 admite las opciones `--jit`, `--sin-jit` y `--sin-optimizar` para controlar la compilación JIT y las optimizaciones durante la ejecución. Quetzal sigue siendo un lenguaje interpretado: el JIT es una optimización interna para funciones compatibles.

## Comprobar la instalación

Crea un archivo `hola_mundo.qz`:

```qz
consola.mostrar_exito("¡Hola, mundo desde Quetzal!")
```

Ejecuta el archivo:

```bash
quetzal hola_mundo.qz
```

## Extensiones para editores

El servidor `quetzal-lsp` proporciona diagnósticos, autocompletado, información de símbolos y navegación a definiciones. Las extensiones oficiales lo integran con los editores:

- [Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=AntaresGT.lenguaje-quetzal-vscode-extension): `code --install-extension AntaresGT.lenguaje-quetzal-vscode-extension`
- [Neovim](https://github.com/AntaresGT/lenguaje-quetzal.nvim)
- [Zed](https://github.com/AntaresGT/lenguaje-quetzal-zed-extension)

## Actualizar Quetzal

Descarga el paquete de la nueva versión y reemplaza la instalación anterior, o vuelve a compilar el código fuente actualizado. Después ejecuta `quetzal --version` para confirmar la versión activa.
