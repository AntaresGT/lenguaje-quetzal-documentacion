## Versión actual: v0.0.3

Lenguaje Quetzal v0.0.3 mantiene las características de v0.0.2 e incorpora:

- Optimizaciones de la máquina virtual, el bytecode, las llamadas a funciones y los bucles.
- Compilación JIT selectiva mediante Cranelift para funciones compatibles.
- Opciones `--jit`, `--sin-jit` y `--sin-optimizar`.
- Servidor de lenguaje `quetzal-lsp` con diagnósticos, autocompletado y navegación a definiciones.
- Extensiones para Visual Studio Code, Neovim y Zed.
- Ejecutables `quetzal` y `quetzal-lsp` en los paquetes de Windows y Linux.
- Mejoras de estabilidad, manejo de excepciones y compatibilidad con programas existentes.
- Interrupción de sentencias `mientras`.

Consulta las [notas completas de v0.0.3](https://github.com/AntaresGT/lenguaje-quetzal/releases/tag/v0.0.3).

## v0.0.2

- Tipado estático explícito e inmutabilidad predeterminada con `var`.
- Módulos de usuario con `importar` y `exportar`.
- Excepciones con `intentar`, `capturar`, `finalmente` y `lanzar`.
- Herencia simple y múltiple, prototipos y miembros `libre`.
- Funciones asíncronas y callbacks nombrados.
- Listas, JSON nativo y métodos integrados por tipo.
- Biblioteca estándar de consola, matemáticas, tiempo, expresiones regulares, archivos y red.
- Manifiesto `quetzal.json` y permisos declarativos.
- REPL interactivo.

## v0.0.1

- Intérprete básico implementado en Rust.
- Tipos de datos fundamentales y funciones definidas por el usuario.
- Condicionales, bucles y JSON nativo.
- Extensión para Visual Studio Code.

## Próximas versiones

La dirección publicada por el proyecto para v0.1.0 incluye:

- Gestión de paquetes más madura.
- Debugger integrado.
- APIs REST más completas para entornos de producción.
- Conexión a bases de datos.
- Herramientas de desarrollo adicionales.

Las propuestas para versiones posteriores pueden cambiar. Los [lanzamientos en GitHub](https://github.com/AntaresGT/lenguaje-quetzal/releases) son la referencia para conocer las características publicadas.
