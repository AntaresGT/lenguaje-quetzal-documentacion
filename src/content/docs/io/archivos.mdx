El módulo `quetzal/sistema_archivos` permite trabajar con archivos de texto o binarios, directorios, flujos con cursor y observadores de cambios.

<Aside type="caution">
Las operaciones con archivos requieren el permiso `sistema-archivos` en `quetzal.json`. Sin ese permiso, el intérprete bloquea el acceso.
</Aside>

## Configurar permisos

Declara cada directorio y el nivel de acceso necesario:

```json
{
  "versión": "1.0.0",
  "aplicación": "mi-proyecto",
  "entrada": "principal.qz",
  "tipo": "aplicación",
  "quetzal": "0.0.3",
  "permisos": [
    {
      "tipo": "sistema-archivos",
      "habilitado": true,
      "directorios": [
        { "ruta": "./datos", "permiso": "lectura" },
        { "ruta": "./salida", "permiso": "escritura" }
      ]
    }
  ]
}
```

Los niveles disponibles son `lectura`, `escritura` y `todo`. Las rutas relativas se resuelven desde la raíz del proyecto; `"*"` permite cualquier ruta.

## Leer y escribir texto

```qz
importar { SistemaArchivos } desde "quetzal/sistema_archivos"

SistemaArchivos.crear_directorios("./salida")
SistemaArchivos.escribir("./salida/resultado.txt", "Hola, Quetzal")

texto contenido = SistemaArchivos.leer("./salida/resultado.txt")
consola.mostrar(contenido)
```

`escribir` crea o sobrescribe el archivo. Para agregar contenido al final, usa `anexar`.

## Consultar archivos y directorios

```qz
log existe = SistemaArchivos.existe("./salida/resultado.txt")
log es_archivo = SistemaArchivos.es_archivo("./salida/resultado.txt")
lista<texto> archivos = SistemaArchivos.listar_archivos("./salida")
```

También puedes obtener una referencia con metadatos:

```qz
importar { SistemaArchivos, Archivo } desde "quetzal/sistema_archivos"

Archivo archivo = SistemaArchivos.abrir("./salida/resultado.txt")
consola.mostrar(archivo.nombre())
consola.mostrar(archivo.tamaño().texto())
```

## Datos binarios

`Bits` representa una secuencia de bytes en memoria:

```qz
importar { SistemaArchivos, Bits } desde "quetzal/sistema_archivos"

Bits datos = Bits.desde_texto("Quetzal")
SistemaArchivos.escribir_bits("./salida/datos.bin", datos)

Bits leidos = SistemaArchivos.leer_bits("./salida/datos.bin")
consola.mostrar(leidos.texto())
```

## Operaciones asíncronas

Las operaciones de entrada y salida tienen una variante con el sufijo `_asincrono`, que se utiliza con `esperar`:

```qz
asincrono vacio guardar() {
    esperar SistemaArchivos.escribir_asincrono("./salida/datos.txt", "contenido")
    texto datos = esperar SistemaArchivos.leer_asincrono("./salida/datos.txt")
    consola.mostrar(datos)
}

esperar guardar()
```

## Manejar errores

Los permisos insuficientes, las rutas no autorizadas y los errores del sistema operativo producen excepciones capturables:

```qz
intentar {
    texto contenido = SistemaArchivos.leer("./datos/config.txt")
    consola.mostrar(contenido)
} capturar (excepcion error) {
    consola.mostrar_error(error.mensaje)
}
```

El módulo también incluye `Flujo` para lectura y escritura por partes con un cursor persistente, y `Observador` para recibir eventos de cambios en archivos o directorios.
