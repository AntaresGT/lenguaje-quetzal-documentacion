---
title: Funciones asíncronas
description: Declaración y ejecución de funciones asíncronas con asincrono y esperar en Lenguaje Quetzal.
---

Las funciones asíncronas están disponibles en Lenguaje Quetzal. Se declaran con `asincrono` (o `asincróno`) y sus resultados se obtienen con `esperar`.

## Declarar una función asíncrona

El modificador se coloca antes del tipo de retorno:

```qz
asincrono entero doble(entero valor) {
    retornar valor * 2
}
```

## Esperar el resultado

`esperar` puede utilizarse dentro de otra función asíncrona o en el nivel superior del archivo de entrada:

```qz
asincrono entero doble(entero valor) {
    retornar valor * 2
}

entero resultado = esperar doble(21)
consola.mostrar(t"Resultado: {resultado}")
```

Dentro de una función:

```qz
asincrono vacio ejecutar() {
    entero resultado = esperar doble(10)
    consola.mostrar(resultado.texto())
}

esperar ejecutar()
```

## Operaciones asíncronas de la biblioteca estándar

Los módulos de sistema de archivos y red proporcionan variantes con el sufijo `_asincrono`. Estas variantes permiten que el bucle de eventos continúe atendiendo otras operaciones.

```qz
importar { SistemaArchivos } desde "quetzal/sistema_archivos"

asincrono vacio copiar_datos() {
    texto datos = esperar SistemaArchivos.leer_asincrono("./entrada.txt")
    esperar SistemaArchivos.escribir_asincrono("./salida.txt", datos)
}

esperar copiar_datos()
```

El acceso a archivos requiere los permisos correspondientes en `quetzal.json`.

## Reglas

- El tipo de retorno se declara después de `asincrono`.
- `esperar` se escribe antes de la llamada que produce la tarea.
- Los parámetros, el retorno y las excepciones siguen las mismas reglas de tipos que las funciones síncronas.
- Los callbacks asíncronos se declaran con nombre; Quetzal no tiene funciones anónimas.
