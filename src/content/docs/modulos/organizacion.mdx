## Crear un proyecto

El comando `nuevo` genera la estructura inicial:

```bash
quetzal nuevo mi-proyecto
```

Una estructura habitual es:

<FileTree>
- mi-proyecto/
  - quetzal.json
  - principal.qz
  - modulos/
    - usuarios.qz
    - utilidades.qz
  - datos/
</FileTree>

Los archivos de código usan la extensión `.qz`. Las importaciones entre archivos utilizan rutas relativas:

```qz
importar { Usuario } desde "./modulos/usuarios.qz"
```

## Manifiesto `quetzal.json`

El manifiesto define los metadatos, el archivo de entrada, la versión de Quetzal, las dependencias y los permisos del proyecto. Sus campos canónicos conservan las tildes.

```json
{
  "versión": "1.0.0",
  "aplicación": "mi-proyecto",
  "entrada": "principal.qz",
  "tipo": "aplicación",
  "quetzal": "0.0.3",
  "dependencias": {}
}
```

| Campo | Descripción |
|-------|-------------|
| `versión` | Versión del formato del manifiesto. |
| `aplicación` | Nombre del proyecto. |
| `entrada` | Archivo `.qz` principal. |
| `tipo` | `aplicación` para un programa o `biblioteca` para código importable. |
| `quetzal` | Versión del lenguaje requerida. |
| `dependencias` | Dependencias y sus versiones o URL. |

<Aside type="note">
Sin `quetzal.json`, el intérprete aplica valores seguros de forma predeterminada y bloquea el acceso a archivos y red.
</Aside>

## Permisos

Los permisos disponibles son `sistema-archivos`, `red`, `entorno` y `ejecución`.

```json
{
  "versión": "1.0.0",
  "aplicación": "mi-proyecto",
  "entrada": "principal.qz",
  "tipo": "aplicación",
  "quetzal": "0.0.3",
  "permisos": [
    {
      "tipo": "sistema-archivos",
      "habilitado": true,
      "directorios": [
        { "ruta": "./datos", "permiso": "lectura" },
        { "ruta": "./salida", "permiso": "todo" }
      ]
    },
    {
      "tipo": "red",
      "habilitado": true
    }
  ]
}
```

Para el sistema de archivos, cada directorio declara `lectura`, `escritura` o `todo`. El permiso `red` habilita clientes y servidores HTTP. El permiso `entorno` permite consultar variables del sistema y cargar archivos `.env`. El permiso `ejecución` incluye una lista `ejecutables` con los procesos externos autorizados.

Concede únicamente los permisos y rutas que el programa necesita.

## Módulos nativos

```qz
importar { Matemática } desde "quetzal/matemática"
importar { Tiempo } desde "quetzal/tiempo"
importar { ExpresiónRegular } desde "quetzal/motor"
importar { entorno } desde "quetzal/entorno"
importar { SistemaArchivos } desde "quetzal/sistema_archivos"
importar { ClienteHttp } desde "quetzal/red"
```
