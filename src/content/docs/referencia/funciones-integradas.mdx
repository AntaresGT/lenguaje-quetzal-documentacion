Quetzal incluye el objeto global `consola`, la función `rango`, métodos para los tipos del lenguaje y módulos nativos que se importan desde rutas `quetzal/...`.

## Consola

El objeto `consola` está disponible sin importarlo.

| Método | Descripción |
|--------|-------------|
| `consola.mostrar(texto)` | Muestra una línea con el color predeterminado. |
| `consola.mostrar_error(texto)` | Muestra un mensaje de error. |
| `consola.mostrar_advertencia(texto)` | Muestra una advertencia. |
| `consola.mostrar_exito(texto)` | Muestra un mensaje de éxito. |
| `consola.mostrar_informacion(texto)` | Muestra información. |
| `consola.pedir(texto)` | Lee una línea escrita por el usuario. |
| `consola.pedir_secreto(texto)` | Lee una línea sin mostrar la entrada. |

Los métodos de salida reciben `texto`. Para mostrar otro tipo, usa `.texto()` o interpolación con `t"..."`.

## Función `rango`

`rango(inicio, fin)` genera una lista de enteros desde `inicio` hasta `fin`, **incluyendo ambos extremos**. Requiere dos argumentos.

```qz
lista<entero> numeros = rango(2, 5)  // [2, 3, 4, 5]
lista<entero> desde_cero = rango(0, 3)  // [0, 1, 2, 3]
```

## Métodos de `texto`

| Operación | Métodos |
|-----------|---------|
| Tamaño y estado | `longitud()`, `esta_vacia()` |
| Mayúsculas y minúsculas | `mayusculas()`, `minusculas()`, `capitalizar()`, `titulo()` |
| Recorte | `recortar()`, `recortar_inicio()`, `recortar_final()` |
| Búsqueda | `contiene(texto)`, `empieza_con(texto)`, `termina_con(texto)`, `encontrar(texto)`, `buscar_ultimo(texto)`, `contar(texto)` |
| Comparación | `igual_sin_caso(texto)` |
| Reemplazo | `reemplazar(anterior, nuevo)`, `reemplazar_primero(anterior, nuevo)` |
| División | `dividir(separador)`, `partir_lineas()` |
| Extracción | `subtexto(inicio, fin)`, `izquierda(n)`, `derecha(n)` |
| Transformación | `repetir(n)`, `invertir()` |
| Validación | `es_numero()`, `es_entero()`, `es_alfanumerico()` |
| Codificación | `a_base64()`, `decodificar_base64()`, `a_enlace()`, `decodificar_enlace()` |
| Conversión | `texto()`, `entero()`, `numero()` / `número()`, `logico()`, `lista()`, `jsn()` |

```qz
texto mensaje = "  Hola Quetzal  "
texto limpio = mensaje.recortar()
log contiene = limpio.contiene("Quetzal")
lista<texto> palabras = limpio.dividir(" ")
texto codificado = limpio.a_base64()
```

Los índices comienzan en cero y los negativos cuentan desde el final:

```qz
texto palabra = "Quetzal"
texto primera = palabra[0]   // "Q"
texto ultima = palabra[-1]  // "l"
```

## Métodos de `lista` y `lista<T>`

| Operación | Métodos |
|-----------|---------|
| Tamaño y estado | `longitud()`, `esta_vacia()` |
| Acceso | `primero()`, `ultimo()`, `[indice]` |
| Modificación | `agregar(valor)`, `insertar(indice, valor)`, `remover(valor)`, `quitar_en(indice)`, `limpiar()` |
| Búsqueda | `contiene(valor)`, `buscar(valor)`, `buscar_ultimo(valor)`, `contar(valor)` |
| Orden | `ordenar()`, `ordenar_descendente()`, `ordenado()`, `invertir()` |
| Sublistas | `tomar(n)`, `saltar(n)`, `sublista(inicio, fin)` |
| Combinación | `concatenar(otra)`, `extender(otra)` |
| Listas numéricas | `sumar()`, `promedio()`, `maximo()`, `minimo()` |
| Conversión | `unir(separador)`, `texto()`, `json()`, `logico()` |

```qz
lista<entero> var numeros = [3, 1, 2]
numeros.agregar(4)
numeros.ordenar()

entero total = numeros.sumar()       // 10
texto valores = numeros.unir(", ") // "1, 2, 3, 4"
```

<Aside type="note">
Los métodos que modifican una lista, como `agregar`, `ordenar`, `invertir` o `extender`, requieren que la lista esté declarada con `var`.
</Aside>

## Métodos de `jsn`

| Método | Descripción |
|--------|-------------|
| `contiene_clave(clave)` | Comprueba si existe una clave. |
| `claves()` | Devuelve la lista de claves. |
| `valores()` | Devuelve la lista de valores. |
| `establecer(clave, valor)` | Crea o modifica una propiedad. |
| `eliminar(clave)` | Elimina una propiedad. |
| `fusionar(otro)` | Combina las propiedades de otro objeto JSON. |
| `texto()` | Serializa el valor como JSON. |
| `texto_formateado()` | Serializa el valor con formato legible. |

```qz
jsn persona = { nombre: "Ana", edad: 30 }
persona.establecer("activo", verdadero)

lista<texto> campos = persona.claves()
texto serializado = persona.texto_formateado()
```

## Métodos numéricos y lógicos

Los valores `entero` y `número` admiten `texto()`, `logico()`, `absoluto()`, `entero()` y `numero()` / `número()`. Los valores `log` admiten `texto()`.

```qz
texto entero_como_texto = 42.texto()
número desde_entero = 42.número()
entero truncado = 3.99.entero()  // 3
log distinto_de_cero = 1.logico()  // verdadero
texto logico_como_texto = falso.texto()
```

## Módulos nativos

| Importación | Símbolos principales | Funcionalidad |
|-------------|----------------------|---------------|
| `"quetzal/matemática"` | `Matemática` | Aritmética, trigonometría, logaritmos, estadística y números aleatorios. |
| `"quetzal/tiempo"` | `Tiempo` | Fechas, horas, zonas horarias, formato y aritmética temporal. |
| `"quetzal/motor"` | `ExpresiónRegular` | Búsqueda, validación, reemplazo y división mediante expresiones regulares. |
| `"quetzal/entorno"` | `entorno` | Variables del sistema y carga de archivos `.env`. Requiere el permiso `entorno`. |
| `"quetzal/sistema_archivos"` | `SistemaArchivos`, `Archivo`, `Bits`, `Flujo`, `Observador`, `EventoArchivo` | Archivos de texto y binarios, directorios, flujos y observación de cambios. Requiere el permiso `sistema-archivos`. |
| `"quetzal/red"` | `ServidorHttp`, `ClienteHttp`, `Enrutador`, `Formulario`, `HttpCodigos`, entre otros | Servidores y clientes HTTP, peticiones asíncronas y formularios multipart. Requiere el permiso `red`. |

### Matemática

```qz
importar { Matemática } desde "quetzal/matemática"

número area = Matemática.PI * Matemática.potencia(5, 2)
entero dado = Matemática.aleatorio_rango(1, 6)
```

Constantes: `PI`, `TAU` y `E`.

- Aritmética: `sumar`, `restar`, `multiplicar`, `dividir`, `potencia`, `absoluto`.
- Trigonometría: `seno`, `coseno`, `tangente`, `grados_a_radianes`, `radianes_a_grados`, `hipotenusa`.
- Logaritmos y raíces: `logaritmo`, `logaritmo_base`, `exponencial`, `raiz_cuadrada`.
- Redondeo: `redondear`, `piso`, `techo`.
- Estadística: `promedio`, `maximo`, `minimo`, `suma_total`, `producto_total`.
- Aleatorios: `aleatorio`, `aleatorio_rango`.

### Tiempo

```qz
importar { Tiempo } desde "quetzal/tiempo"

Tiempo actual = Tiempo.ahora()
Tiempo mañana = actual.agregar_dias(1)
consola.mostrar(actual.formatear("%d/%m/%Y"))
```

Incluye constructores, `ahora`, `ahora_utc`, `ahora_en`, `hoy`, `marca`, `desde_marca`, `analizar`, componentes de fecha, formateo, comparación, aritmética temporal y conversión entre zonas horarias.

### Expresiones regulares

```qz
importar { ExpresiónRegular } desde "quetzal/motor"

ExpresiónRegular numeros = nuevo ExpresiónRegular("\\d+")
log coincide = numeros.coincide("abc123")
lista coincidencias = numeros.buscar_todo("a1 b22 c333")
```

### Entorno

```qz
importar { entorno } desde "quetzal/entorno"

entorno.cargar()
texto modo = entorno.obtener_o("MODO", "desarrollo")
```

El módulo incluye `cargar`, `obtener`, `obtener_o` y `contiene`. Requiere el permiso `entorno`. Consulta [Variables de entorno](/io/entorno) para ver la referencia completa.

### Sistema de archivos

```qz
importar { SistemaArchivos } desde "quetzal/sistema_archivos"

SistemaArchivos.escribir("./salida.txt", "Hola")
texto contenido = SistemaArchivos.leer("./salida.txt")
```

Las operaciones de entrada y salida tienen formas síncronas y asíncronas con el sufijo `_asincrono`. Consulta [Manejo de archivos](/io/archivos) para configurar los permisos.

### Red

```qz
importar { ClienteHttp, RespuestaHttp } desde "quetzal/red"

ClienteHttp cliente = nuevo ClienteHttp({ base_url: "https://api.ejemplo.com" })
RespuestaHttp respuesta = esperar cliente.obtener_asincrono("/usuarios")
consola.mostrar(respuesta.estado().texto())
```

Los métodos HTTP se escriben en español: `obtener`, `publicar`, `poner`, `parchear`, `borrar`, `cabecera`, `opciones`, `consultar`, `rastrear` y `conectar`.
